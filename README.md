# Multilingual Love Heart ❤️

A generative typographic art piece that draws a heart out of "I love you" in 22 languages, with smooth floating animations and a soft shimmer.

**Live demo:** https://krismit.github.io/Heart/

## Features
- **Parametric heart boundary:** every phrase is placed inside a parametric heart curve, so the text forms the silhouette exactly.
- **Multilingual typography:** French "Je t'aime" and Serbian "Volim te" always appear side by side, together with Macedonian "Сакам те", Greek "Σ' αγαπώ", Swedish, and 17 other languages.
- **Smooth animation:** each word floats in with a cubic ease-out and a colour gradient from deep wine to crimson.
- **Shimmer:** once the heart is complete, random words keep glinting.
- **Runs anywhere:** a single self-contained `index.html` with no dependencies. Tap the heart to replay.

## How to run
Open `index.html` in any browser, or visit the live demo link.
